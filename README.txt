# KampusUpdate - Blog/Berita WordPressWebsite media informasi mahasiswa berbasis WordPress.## Teknologi- WordPress 7.1.3- PHP 8.2.29- Database MySQL 8.4.0- Web server: nginx (LocalWP)## Theme- **Blocksy** + Blocksy Companion- Custom CSS untuk Beranda (hero, ticker kategori, kartu melayang)## Plugin| Plugin | Fungsi ||---|---|| Elementor | Page builder || LiteSpeed Cache | Caching dan optimasi || WP Activity Log | Pencatatan aktivitas || Joinchat | Tombol WhatsApp || UpdraftPlus | Backup website || Blocksy Companion | Pendamping theme Blocksy |## Konfigurasi yang dilakukan- Site title dan tagline diisi- Permalink: Post name- Homepage: static page (Beranda), halaman posts: Blog- Menu navigasi: Beranda, Blog, Tentang Kami- Kategori: Pengabdian, Prestasi, Teknologi, Berita Kampus- 10+ artikel dummy dengan featured image, kategori, dan tag- Template Detail Blog: featured image, meta, author box, tags, related posts- Joinchat: nomor WhatsApp dan pesan sapaan diatur- UpdraftPlus: jadwal backup diatur dan satu backup manual berhasil- WP Activity Log aktif dan mencatat aktivitas- LiteSpeed Cache: cache aktif- Username admin bukan "admin", password kuat- Plugin yang tidak diperlukan dihapus## Cara menjalankan lokal (LocalWP)1. Install LocalWP (localwp.com).2. Buat situs baru, atau import file backup/zip situs.3. Start site, lalu buka kampusupdate.local.4. Login lewat WP Admin.## Link- Website: (isi URL Live Link)- GitHub: (isi link repo)
